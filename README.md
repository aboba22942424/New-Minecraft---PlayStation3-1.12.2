# New-Minecraft---PlayStation 3-1.12.2
Minecraft: PlayStation 3 Edition+ — амбициозный проект по воссозданию механик ПК-версии 1.12.2 на базе собственного C++ движка для PS3. Архитектура оптимизирована под Cell BE: расчет геометрии чанков (chunk_mesher), менеджмент памяти и физика работают независимо. Поддерживает кастомные ассеты и сборку в PKG/ISO для работы на HEN/CFW.
