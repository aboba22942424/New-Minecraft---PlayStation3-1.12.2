# Minecraft: PlayStation 3 Edition+ 🚀

Добро пожаловать в репозиторий **Minecraft: PlayStation 3 Edition+**! Это амбициозный и по-настоящему крутой проект, цель которого - перенести возможности и механики ПК-версии 1.12.2 на культовую консоль PS3. 

---

## ⚙️ Движок проекта (Engine)

Проект полностью базируется и работает на кастомном движке **DuoPsSell Engine v1.0**. 
Вся разработка ведется с нуля на языке C++ и оптимизирована специально под архитектуру процессора Cell BE. Внутри движка реализованы собственные системы рендеринга, обработки чанков и управления ресурсами консоли.

---

## 📊 Потребление ресурсов и производительность

Движок DuoPsSell проектируется с учетом жестких аппаратных ограничений PlayStation 3:
* **Распределение памяти:** Логика игры, GUI и физика оптимизированы для экономного использования RAM, чтобы оставлять максимальный запас для графического конвейера.
* **Многопоточность:** Генерация и сборка геометрии чанков (`chunk_mesher`), а также менеджмент данных (`chunk_manager`) выносятся в отдельные потоки для эффективной утилизации мощностей процессора Cell.
* **Оптимизация:** Движок нацелен на обеспечение стабильной частоты кадров за счет умного кэширования геометрии и стриминга данных.
